# Security

Report security issues privately through GitHub Security Advisories:

https://github.com/joshkeldam/databento-stream-downloader/security/advisories/new

Maintainer: `@joshkeldam`.

Do not open public issues for leaked credentials, unsafe default behavior, or
archive-integrity vulnerabilities.

Generated ledgers include local host and user fields. Treat ledger files as
private operational metadata unless those fields have been redacted.

## Supported Versions

Security fixes target the latest released version.
